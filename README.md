# Esquecedário

Um diário que esquece. As palavras se apagam com o tempo; para mantê-las, é preciso lembrá-las.

Abra no celular e instale: no iPhone, Safari → Compartilhar → Adicionar à Tela de Início; no Android, Chrome → Instalar app.
As notas ficam só no aparelho. Nada é enviado para servidor nenhum.
