Como funciona

  1. lembrança

    Escreva

    Guarde uma nota. Depois de guardada, ela não pode ser editada, só lembrada.

  2. lembrança

    Esqueça

    Palavra por palavra, a tinta passa do azul-ferro à ferrugem e some. Você escolhe se isso leva dias, semanas ou meses.

  3. le_b__ça

    Lembre

    Volte e reescreva o que sumiu. Lembrar com esforço segura a palavra por muito mais tempo do que só reler.

        Ajustes

        Como funciona
        1. Cada palavra que você guarda começa a se apagar, seguindo uma curva de esquecimento. As letras somem uma a uma e a tinta passa do azul-ferro à ferrugem.
        2. Para salvar uma palavra, clique na lacuna e escreva o que estava ali. Acertar de memória faz a palavra durar muito mais antes de voltar a se apagar do que só reler, e quanto mais apagada ela estava, mais tempo ela ganha. Erros de uma letra em palavras longas são aceitos, mas a palavra ganha menos tempo antes de voltar a se apagar.
        3. Dica mostra uma letra a mais da palavra. Cada lembrança tem direito a uma dica só, e a palavra recuperada com dica dura menos antes de voltar a se apagar. Se ainda assim não vier, deixe para depois: a palavra continua ali até sumir.
        4. A sessão do dia junta as lacunas mais urgentes de todas as notas, em 2 minutos.
        5. Relembrar devolve uma nota inteira de uma vez, mas cobra um preço: outra lembrança, sorteada, perde metade das palavras que ainda tem e passa a se apagar duas vezes mais rápido.
        6. Quando menos de 5% das letras restam, o texto é apagado deste navegador de verdade. Fica a forma das palavras e, se você quiser, as palavras que recuperou de memória.

        Tudo fica guardado só neste navegador, neste aparelho. Nada é enviado para lugar nenhum.

        Avisos

        O navegador avisa quando uma nota marcada como importante estiver em risco, mas só enquanto o Esquecedário estiver aberto numa aba. Para ser lembrado com tudo fechado, use Lembrete na agenda dentro da nota.

        Levar para outro aparelho

        O arquivo leva as notas com os horários de cada palavra, então o esquecimento continua de onde parou. Uma nota que já foi esquecida aqui não volta ao importar.

        Sair apaga tudo deste aparelho, para sempre. Todas as lembranças, as esquecidas, as estatísticas, o seu nome e os ajustes serão perdidos permanentemente, e o Esquecedário volta à apresentação inicial. Não há como desfazer.

        Se quiser guardar as notas, use Baixar arquivo acima antes de sair.
